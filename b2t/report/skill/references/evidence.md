# Evidence：方法、证据与结论

当主要理解任务是判断某个结果如何获得、证据支持什么结论时使用。出现数字或引用研究不自动构成实证主线。

本 Profile 只指导内容关系表达；内容取舍与展开程度服从本次所选模式，不要求补回该模式已省略的次要内容。

## 编辑重点

- 围绕问题连接方法、样本或测试条件、观察结果及结论，区分实测、转述和解释。
- 比较时保留对象、指标、单位、基准及可比条件；不同口径分别展示。
- 让影响结论范围的限制紧邻结果，不将关键限制仅收进页尾说明。
- 主要发现与决定性限制放在一起，证据路径直接承担正文；按所选深度保留方法、数据、例子与推导。

## 可选表达

使用 Evidence Chain 展示问题到结论的联系，表格组织多对象、多指标比较。数量图沿用全局规则，仅在图形确实降低比较成本时使用；机制图可解释结果，但不代替实证依据。

## 长说明如何退出表格：示例

假设来源按三个主题汇总新闻，每个主题都有出现次数和多条具体事件。

- 弱表达：表格只有“主题／次数／代表条目”三列，却把十条新闻连成一大段放进最后一格，前两列被挤成逐字换行。
- 更清楚：表格比较主题与次数，只放简短代表条目；所选模式保留的事件按主题在表格后分组列出，不重复已呈现的条目。事件本就简短时，也可保留在单元格内，用原生列表分隔，并给类别、次数列分配宽度。

表格宽度、配色与具体组件由所选模式决定；文字过长时按该模式取舍或移出表格。保留事件日期、统计口径及“约”等限定，不为腾空间只留下醒目的数字。

## 失真提醒

不将单次结果、局部样本或特定配置扩大为普遍结论，不把相关性当作因果。方法或限制未被交代时，不凭常识补齐研究设计，也不虚构缺陷；只说明影响当前理解的实际缺口。
