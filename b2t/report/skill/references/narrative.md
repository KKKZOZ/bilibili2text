# Narrative：事件、转折与后果

当主要理解任务是跟随事件理解人物、局势或结果如何变化时使用。故事、案例或实况可适用，题材本身不决定主线。

本 Profile 只指导内容关系表达；内容取舍与展开程度服从本次所选模式，不要求补回该模式已省略的次要内容。

## 编辑重点

- 建立理解事件所需的初始状态、人物关系与背景，围绕改变局势的关键事件推进。
- 区分事件、选择、触发条件和后果；保留理解转折所必需的过程，不逐分钟复述。
- 来源支持时交代人物认知或目标的变化；重复场景可合并，但不抹去改变结果的偶然因素与失败过程。
- 直接呈现关键进展及转折，按所选深度保留重要场景、背景与解释，不强行总结人生道理。

## 可选表达

使用 Timeline / Turning Points 呈现事件顺序与转折，Before → Trigger → After 对照同一对象的状态变化。人物或资源关系复杂时可用 Relationship Map；连贯叙事仍可使用正常段落。

## 失真提醒

不将先后发生的事件直接连成因果，不根据最终结果倒推出人物动机或必然路径。事件日期与视频时间戳分别处理；回忆、推测和当事人说法保留原有性质。
