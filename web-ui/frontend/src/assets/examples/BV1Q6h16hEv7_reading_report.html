1剧烈亏钱效应下的缩量下跌00:02–01:45

第1277天，亏钱效应十分剧烈，持仓股基本都在回落，整体亏损约一个点，与指数基本齐平。

约2:1收盘时下跌家数与上涨家数之比
4:1–5:1盘中低位发动态时两者之比

下跌家数达到1200多，上涨600多；盘中低位发动态时，两者比例一度到4:1到5:1，收盘指数回升后才收窄到上述水平。在亏钱效应这么强的日子里，少亏当赢。

核心线索：10年期美债收益率

持续上升的10年期美债收益率是这轮下跌的核心原因：收益率上升意味着债券价格越砸越低，当前收益率可以达到5%，持有10年到期就能拿到这个收益，并且由美国政府担保。这个5%没有调整通胀，是名义利率，实际收益还要剔除通胀率。

港股通停用后的极致缩量

当天港股通无法使用，只有纯香港账户可以进行交易，成交额因此很小。几笔成交就能砸掉上亿市值：

  • 400万成交 — 砸掉约1亿市值。
  • 中海 — 500万成交砸掉约2亿市值。
  • 保利 — 约300万成交砸掉接近3亿市值。

这些成交量与前几天的大柱子相比极其微小。

在只有纯香港账户可以交易的情况下，成交额太小，这几笔上亿市值的下跌对定价的参考意义有限。

2福寿园：董事会分歧、停牌与0.1元要约01:44–04:15

福寿园更新了一组公告，补充了此前关于罢免执行董事王继生的内容，把理由写得更明白。

董事会与安永一方

  • 补充公告 — 明确写出罢免执行董事王继生的理由。
  • 法证调查 — 公司此前启动法证调查，要求王继生提供相关证据并到场陈述，但他拒不出面。
  • 评估结论 — 公司相关人士评估后认为，王继生的诉求没有依据。

王继生一方

  • 调查程序 — 不认同选聘安永来进行调查。
  • 范围与方法 — 不认同安永的调查范围和他的调查方法。
  • 结果与公告 — 不认同安永的调查结果，认为过去公司发的公告都不准确。
  • 管理层 — 认为管理层对相关事情的处理不当。

公告等于把两派的分歧摆到台面上：一方是现行董事会，由谭家与白家等其余董事组成；另一方是王继生一派。王继生原本是公司实际执行层面的CEO。

停牌与复牌条件

公司继续执行停牌并推进内控审核。等双方就如何定性、要不要追责达成一致，还要由安永出具一份内控已经完全合规的报告并提交港交所，福寿园才会复牌。

0.1元的收购要约

有人提到一份以0.1元收购福寿园股份的要约公告。这来自一名秃鹫型投资者，走完相关手续之后就可以发起要约。对这种要约不予理会即可：0.1元的价格太低，除非真的急着用钱、愿意不计代价把股份按零头割掉，否则没有必要接受。

  2. 大账户同步卖出

    大账户日内同步卖出20万中海物业，把A账户的股票慢慢搬运到B账户。
